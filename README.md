# Organizador de Declaração de Imposto de Renda

## 📊 Sobre o projeto

Projeto desenvolvido durante o curso da DIO com o objetivo de criar um organizador para auxiliar no gerenciamento das informações necessárias para a Declaração de Imposto de Renda.

## 🎯 Objetivo

Organizar e facilitar o controle das informações utilizadas na preparação da declaração, tornando o processo mais estruturado e prático.

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Organização e análise de dados
- Fórmulas e recursos de Excel
